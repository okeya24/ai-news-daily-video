# AI 新闻边角料 · 每日短视频 Agent 规则手册

> 可复用的「每日资讯播报短视频」生产模板。本手册沉淀选题、文案、视觉、配音、合成、质检的全套规则；换一个主题（如每日科技、每日财经、每日游戏）只需改第 10 节列出的变量，无需重做流程。

## 1. 成品规格

- 画幅：竖屏 9:16，1080×1920，30fps，H.264 + AAC 44.1kHz 立体声
- 条数：每天 5 条热点 + 开场 + 结尾
- 片长：约 2 分 10 秒 ~ 2 分 30 秒（语速适中偏快）
- 风格：黑白铅笔速写 / 新闻手绘感，米白纸底，衬线标题
- 口吻：轻松资讯播报，每条带一句争议或风险提示

## 2. 目录与文件清单

```
ai-news-daily-video/
├── README.md              # 项目说明与快速开始（仓库门面）
├── config.json             # 可改变量：栏目名、条数、画幅、音色、路径
├── requirements.txt        # Python 依赖
├── build_cards.py          # 卡片模板生成脚本（PIL）
├── build_video.sh         # 视频合成脚本（ffmpeg）
├── docs/
│   └── AGENT_RULES.md      # 本规则手册（复用入口）
├── examples/
│   └── script-sample.md    # 当日口播稿 + 卡片摘要 + 来源链接示例
├── assets/                # 当日素材：插画 news1~5.jpg、分段配音 intro/n1~n5/outro.wav
└── output/
    ├── cards/              # 7 张卡片 PNG（片头 + 5 条 + 结尾）
    ├── seg/                # 分段视频临时文件
    └── ai-news-briefing_YYYY-MM-DD.mp4   # 最终成片
```

> `assets/` 与 `output/` 为运行时生成产物，已在 `.gitignore` 中排除，不进入版本库。

## 3. 每日流水线（定时任务按此顺序执行）

1. **搜集**：按第 4 节 6 个维度检索全球当日动态，中英文都覆盖。
2. **筛选**：去重、剔除旧闻水文，按热度取前 5 条，保留标题、摘要、原文链接。
3. **写稿**：按第 5 节模板写开场、5 条播报、结尾；每条配一句卡片摘要；写入 `script.md`。
4. **出图**：为每条生成一张铅笔速写风插画（白底、无文字、无 Logo），存入 `assets/newsN.jpg`。
5. **配音**：按第 7 节规范分段生成 7 段音频，存入 `assets/`。
6. **合成**：运行 `build_cards.py` 生成卡片，再运行 `build_video.sh` 拼接成片。
7. **质检**：按第 9 节清单复核，重点查语音内容错误；有问题只重配对应段并重新合成。
8. **交付**：成片 + 标题 + 话题标签推送给人工终审发布（当前不自动上传平台）。

## 4. 选题与热度排序规则

### 4.1 六个检索维度（每个维度至少 1 次，总共 8 次以上）

- A 周报 / Newsletter 聚合：`last week in AI`、`AI weekly roundup`、`the batch AI newsletter`
- B 社区热度 / 病毒传播：`viral AI tool`、reddit/HN/GitHub trending、开源项目涨星
- C 产品发布与模型更新：大厂官宣、新模型、新功能
- D 融资与商业：融资、收购、IPO、估值
- E 研究突破：论文、SOTA、技术突破
- F 监管与政策：法规、安全、治理、争议事件

### 4.2 热度信号（权重从高到低）

- 3 家以上不同来源报道同一事件
- 社区病毒传播证据（GitHub 暴涨、X/HN 刷屏）
- 权威来源官宣（大厂、顶会）
- 有真实用户体验分享
- 技术突破性 / 影响范围
- 争议性与讨论度
- 时效性（辅助）

### 4.3 取舍

- 同一事件多源报道合并为一条，选最权威来源，摘要注明"多家媒体报道"。
- 中英文热点都要保留；纯预测、纯软文不收。
- 每条必须保留可溯源的原文链接。

## 5. 文案口径模板

### 5.1 固定开场（替换日期）

> 大家好，这是【栏目名】！{M} 月 {D} 日，全球 {领域} 圈最值得关注的 {N} 条动态，争议和看点都给你摆出来，一分钟看完。

### 5.2 条目结构（每条 2~3 句）

1. **定性 + 事实**：第几条，属于哪类（资本 / 产品 / 国内 / 开源 / 研究…），核心事实与关键数字。
2. **争议 / 风险一句**：点出分歧、未证实之处、潜在风险或争议点（口径要求：必须点名争议，不做单向吹捧）。

示例（第 1 条）：
> 第一条，资本头条。Claude 母公司 Anthropic 的 IPO 获得约六倍超额认购，计划最高募资 904 亿美元……不过争议也不小：英伟达管理层生变，百亿基石认购能否兑现存疑，不少投资者也担心估值是不是把 AI 泡沫一起算进去了。

### 5.3 固定结尾

> 以上就是今天的 {N} 条【栏目名】，关注我，带你看全球 {领域} 边角料，我们明天见。

### 5.4 卡片摘要（精简版，≤2 行，不带句末句号）

- 一行事实 + 一行争议；数字与口播一致。
- 英文专有名词保留原形；中文短句优先。

### 5.5 数字与读法约定（避免 TTS 错读）

- 百分比读中文：`24%` → 百分之二十四
- 大数字读中文：`16 张` → 十六张；`4096` → 四千零九十六；`1.2 万` → 一点二万
- 金额保留阿拉伯数字，如 904 亿美元、1.5 万亿美元
- 模型 / 产品名按英文原形念，不在稿内强行翻译

## 6. 视觉模板规范

### 6.1 风格

- 黑白铅笔速写：线条排线、交叉阴影、米白纸张底、手绘草稿感
- 插画只画场景 / 人物 / 物件，**画面内不出现任何文字、字母、数字、Logo、水印**
- 标题与摘要全部由 `build_cards.py` 后期叠字，保证清晰可控

### 6.2 配色

| 用途 | 色值 |
|---|---|
| 纸底 | #f4efe4 |
| 主文字 | #262421 |
| 次要文字 | #605c54 |
| 强调（编号 / 落款） | #8a6d3b 棕 |
| 边框 / 线条 | #46423a |
| 浅装饰线 | #b4aa96 |

### 6.3 字体（系统 Noto CJK，子字体索引 2 = SC）

- 标题：`Noto Serif CJK SC Bold`（衬线，报刊感）
- 正文：`Noto Sans CJK SC Regular`
- 强调：`Noto Sans CJK SC Medium`

### 6.4 卡片布局（1080×1920）

- 顶部：左栏目名（衬线 38），右日期（Sans 26），下 2px 分隔线
- 插画区：x=80, y=210, 920×1000，cover 裁剪居中，3px 边框
- 编号：衬线 100，棕色，左下
- 标题：衬线 44，最多 2 行
- 摘要：Sans 30，行距 50，最多 4 行（实际控制 2 行内）
- 底部：浅线 + 小字"全球 {领域} 热点 · 每日 {N} 条"

### 6.5 片头 / 结尾卡

- 片头：英文小字 + 居中大栏目名 + 双线装饰 + 日期副标题 + 版本小字
- 结尾：主标题"感谢观看" + 关注引导语 + "我们明天见"

## 7. 配音规范

- 音色：中学年龄段年轻男生，清亮爽朗少年音，带一点东北口语的松弛亲切感（气质相近即可，不复刻特定声优原声）
- 语速：适中偏快，节奏利落，句间停顿简短，吐字清晰不拖沓
- 分段：开场 / 5 条 / 结尾 共 7 段独立生成，便于按段对齐卡片、单段重配
- 无背景音乐（BGM 为后续可选项）
- 每段生成后用 ffprobe 测时长；片段视频以音频实测时长 `-t` 截断，避免尾部拖帧

## 8. 合成流程与命令

### 8.1 生成卡片

```bash
python3 build_cards.py
```

### 8.2 合成成片

```bash
bash build_video.sh
```

脚本要点：
- 每段：`-loop 1` 卡片图 + 对应 wav，`-t` 取音频时长，统一 1080×1920、30fps、yuv420p、AAC 44.1kHz
- 先出 7 个分段 mp4，再 concat 合并重编码，保证各段编码参数一致、兼容各平台

### 8.3 产物校验

- 视频流：h264, 1080×1920, 30fps
- 音频流：aac, 44100Hz, 立体声
- 时长 ≈ 各段音频时长之和；抽帧核对标题、摘要无溢出、无孤行标点

## 9. 产出质检清单（每次出片必过）

**语音内容复核（重点）**
- [ ] 数字与稿一致：金额、百分比、倍数、版本号、分辨率、星标数无错读
- [ ] 专有名词 / 模型名 / 公司名念对，无串名
- [ ] 无漏条、无跳句、无多余口误；开场结尾称呼正确
- [ ] 争议点表述与来源一致，不夸大、不编造结论
- [ ] 如条件允许，对成片音频做转写，与 `script.md` 逐条比对；发现错误只重配对应段

**画面复核**
- [ ] 5 张插画与条目主题对应，无文字乱码、无水印
- [ ] 标题 / 摘要无溢出、无孤行标点、无重叠
- [ ] 日期、栏目名正确

**合规复核**
- [ ] 新闻均可溯源到原文链接
- [ ] 未把预测 / 传闻写成既定事实
- [ ] 不输出侵权肖像、敏感政治内容

## 10. 复用指南：换到别的主题 / 别的视频

只需改下列变量，流程与脚本复用：

| 变量 | 当前值 | 改动位置 |
|---|---|---|
| 栏目名 | AI 新闻边角料 | `config.json` + `build_cards.py` 标题文案 |
| 领域关键词 | AI / 大模型 / Agent | 第 4 节检索词、稿内表述 |
| 条数 | 5 | `config.json`，同步调整卡片与分段数量 |
| 画幅 | 9:16 竖屏 | `build_cards.py` 画布与 `build_video.sh` 尺寸 |
| 插画风格 | 铅笔速写 | 出图 prompt；可换水彩 / 扁平 / 三维等 |
| 配音音色 | 少年男声 | 第 7 节 prompt；可换女声 / 沉稳男声 |
| 口播口吻 | 边角料 + 争议 | 第 5 节模板；可换正式播报 / 深度点评 |
| BGM / 字幕条 | 暂无 | 后续在 `build_video.sh` 增加音轨与字幕烧录 |

### 换主题示例（每日财经 / 每日游戏 / 每日科技）

1. 复制项目目录为新主题目录。
2. 改 `config.json` 的栏目名、领域、条数。
3. 替换第 4 节检索维度关键词；插画 prompt 换成对应场景。
4. 沿用卡片模板与合成脚本，按第 9 节清单质检。

## 11. 已知限制与后续可加项

- **发布**：当前成片 + 文案人工终审后手动上传；未接平台自动发布（需平台开放资质或浏览器登录态）。
- **字幕**：目前卡片静态文字承担信息；旁白逐句跟随字幕条为待加项。
- **BGM**：当前无人声外配乐；可加低音量纯音乐底轨并压人声。
- **数字人 / 动态画面**：当前为静态卡片流；升级动态镜头需另行调用视频生成工具，注意额度与时长。
- **定时任务**：见每日 cron 配置；任务触发后自动跑第 3 节流水线并质检，产出推送给人工终审。
